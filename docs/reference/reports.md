# Reports

BaitBench generates HTML reports via R/rmarkdown with ggplot2 figures. This page describes report modes, available reports, and their sections.

---

## Report Modes

The `--report` flag controls report output for `run`, `probe-coverage`, `coverage-curve`, `assess-probes`, `build-probes`, `panel-qc`, and `report` commands:

| Mode | Description |
|------|-------------|
| `full` (default) | Render the full HTML report using R and pandoc. Requires R with rmarkdown, ggplot2, and DT packages. |
| `none` | Skip report generation entirely. All TSV and JSON outputs are still produced. |
| `rmd` | Write a parameterized RMarkdown file with all paths and parameters pre-filled. Does not require R at run time. |
| `both-r` | Generate both the HTML report and the editable RMarkdown file. |

### Using `--report rmd`

The `rmd` mode produces an `.Rmd` file in the output directory. To render it later:

```bash
Rscript -e 'rmarkdown::render("results/run_20250101_120000/report.Rmd")'
```

Use `rmd` when you want to customize the report before rendering, render on a machine with R, or add project-specific analysis sections without re-running the pipeline.

## Main Pipeline Report (`report.html`)

Generated by `baitbench run` or `baitbench report`.

### Sections

1. **Run Parameters** — Table of all configuration values, plus a reconstructed command line for reproducibility. Shown in a collapsible `<details>` block.

2. **Capture Summary** — Bar chart comparing fragments generated vs captured, broken down by source category (sample, non-sample target, distractor, untargeted).

3. **Detection Performance** — Bar chart of sensitivity, specificity, precision, and F1 score.

4. **Read Mapping Accuracy** — Correctly vs incorrectly mapped reads. High `reads_incorrectly_mapped` indicates cross-mapping (reads from organism A mapping to organism B's reference).

5. **Confusion Matrix** — Heatmap showing TP, FN, FP, and TN counts.

6. **Detection Detail** — Table of every reference sequence with detection status, fragment counts, read counts, and coverage statistics (adapts to dataset size: simple table for ≤20 sequences, interactive DT table for more).

7. **Detection Lollipop** — Reads per detected reference, colored by classification (TP, FP_target, FP_distractor).

8. **Coverage Plots** (if coverage data available) — Per-position read depth for each detected reference. Faceted overview plus expandable per-reference detail. For large panels (>100 sequences), switches to distribution summaries.

9. **Species Identification** (if `--identify`) — Species-level PRESENT/ABSENT/AMBIGUOUS calls. See [Species Identification](#species-identification-section) below.

## Coverage Curve Report (`coverage_curve_report.html`)

Generated by `baitbench coverage-curve`.

### Sections

- **Depth Curves** — Percentage of genome covered (Y-axis) vs coverage depth threshold on a log10 scale (X-axis), one line per parameter combination.
- **Faceting** — With < 10 combinations, all curves on one plot. With ≥ 10 combinations, faceted by the parameter with the fewest levels.
- **Per-target Panels** — If the sample contains multiple targets, each gets its own panel.
- **Summary Table** — Key depth thresholds (1×, 5×, 10×, 20×, 50×, 100×) for each combination.

---

## Probe Coverage Report (`probe_coverage_report.html`)

Generated by `baitbench probe-coverage` or as part of `assess-probes`.

### Sections

- **Summary Table** — Per-target coverage statistics (simple table for ≤20 targets; interactive DT table for more).
- **Coverage Bar Charts** — Per-target 1×/2×/5×/10× breadth (switches to histogram/boxplot for >100 targets).
- **Depth Profiles** — Per-position probe depth plots per target (omitted for >100 targets).
- **Gap Analysis** — Uncovered regions and gap statistics.
- **Multi-mapping Probes** — Probes that align to multiple targets (specificity concern).

---

## Panel QC Report (`panel_qc_report.html`)

Generated by `baitbench panel-qc`.

### Sections

- **Panel Summary** — Total species, targets, similar pairs, and species with zero unique targets.
- **Species Discriminability** — Bar chart (≤50 species) or histogram (>50) of discriminability scores.
- **Target Composition** — Stacked bar chart of unique vs shared targets per species.
- **Species Confusion Matrix** — Heatmap (≤30 species) or distribution statistics (>30) of shared target counts.
- **Discriminability Table** — Full per-species discriminability data (simple table ≤20, interactive DT >20).
- **Target Similarity Pairs** — All pairwise target similarities above the identity threshold.

---

## Probe Assessment Report (`assess_probes_report.html`)

Generated by `baitbench assess-probes` or automatically at the end of `baitbench build-probes`.

### Sections

1. **Build Pipeline** (conditional — only when chained from `build-probes`) — Pipeline stats table, sequence/base count bar charts showing sequence counts after each filter step.

2. **Probe Coverage** — Summary table, coverage breadth bar charts, individual target coverage (always, unless `--no-individual-targets`), combined vs. individual scatter plot, tiered coverage, gap analysis, pangenome depth, per-target depth profiles, proximity coverage, multi-mapping probes.

3. **Gap Details** — Gap count summary (true gaps vs. multimapper gaps), top-20 interactive table (target, coordinates, GC content, sDUST score, gap type, individual coverage), link to full `*_gap_details.tsv`.

4. **Self-Homology** — Plotly interactive heatmap (for ≤1000 probes), density plots, hits table.

5. **Cross-Reactivity vs Genomes** (conditional — only if `--genomes` provided) — Plotly heatmap, per-genome bar chart, density plots, hits table.

6. **Parameters** — Run configuration under a collapsible fold.

---

## Species Identification Section

Included in the main pipeline report when `--identify` is enabled (genome mode).

- **Summary Table** — Species-level sensitivity and specificity (compared against ground truth from `--sample`).
- **Species Call Chart** — Bar chart of PRESENT/ABSENT/AMBIGUOUS calls per species.
- **Evidence Detail Table** — Full breakdown per species: unique/shared targets detected, total reads, which species explains shared hits, call reason.

## Regenerating a Report

To re-render an existing report from the `.Rmd` file:

```bash
Rscript -e 'rmarkdown::render("results/run_20250101_120000/report.Rmd")'
```

Or via the `report` subcommand (passing the existing TSV files):

```bash
baitbench report \
  --summary results/run_20250101_120000/results.tsv \
  --detail results/run_20250101_120000/detected_detail.tsv \
  --params results/run_20250101_120000/run_params.tsv \
  --coverage results/run_20250101_120000/coverage.tsv \
  --output results/run_20250101_120000/report_v2.html
```

This is useful for regenerating a report after upgrading BaitBench's R templates without re-running the full pipeline.
